幂级数求和函数

2026-06-14 数学 128 次浏览

一、通用步骤

数项级数 \(\sum_{n=1}^{\infty} a_n\) 求和的通用方法：

步骤1：识别级数类型

  • 等比级数：\(\sum ar^n\)
  • 幂级数：\(\sum a_n x^n\)
  • 泰勒级数展开

步骤2：确定收敛域

\[R = \lim_{n \to \infty} \left| \frac{a_n}{a_{n+1}} \right|\]

收敛半径 \(R\)，收敛域为 \((-R, R)\)

二、常用幂级数求和公式

1. 几何级数

\[\sum_{n=0}^{\infty} x^n = \frac{1}{1-x}, \quad |x| < 1\]

2. 指数函数

\[\sum_{n=0}^{\infty} \frac{x^n}{n!} = e^x, \quad x \in \mathbb{R}\]

3. 对数函数

\[\sum_{n=1}^{\infty} \frac{x^n}{n} = -\ln(1-x), \quad |x| < 1\]

4. 三角函数

\[\sin x = \sum_{n=0}^{\infty} (-1)^n \frac{x^{2n+1}}{(2n+1)!}\]
\[\cos x = \sum_{n=0}^{\infty} (-1)^n \frac{x^{2n}}{(2n)!}\]

三、求和技巧

技巧1：逐项求导/积分

若 \(S(x) = \sum a_n x^n\)，则：

\(S'(x) = \sum n a_n x^{n-1}\)

\(\int S(x) dx = \sum \frac{a_n}{n+1} x^{n+1}\)

技巧2：变量替换

将复杂级数通过变量替换转化为已知级数形式

技巧3：组合拆分

\[\sum (a_n + b_n) x^n = \sum a_n x^n + \sum b_n x^n\]

四、典型例题

例题1

求 \(\sum_{n=1}^{\infty} n x^{n-1}\) 的和函数

解：

设 \(S(x) = \sum_{n=1}^{\infty} n x^{n-1}\)

积分得：\(\int_0^x S(t) dt = \sum_{n=1}^{\infty} x^n = \frac{x}{1-x}\)

再求导：\(S(x) = \frac{d}{dx}\left(\frac{x}{1-x}\right) = \frac{1}{(1-x)^2}\)

\[\boxed{S(x) = \frac{1}{(1-x)^2}, \quad |x| < 1}\]

例题2

求 \(\sum_{n=1}^{\infty} \frac{x^n}{n(n+1)}\) 的和函数

解：

设 \(S(x) = \sum_{n=1}^{\infty} \frac{x^n}{n(n+1)}\)

利用裂项：\(\frac{1}{n(n+1)} = \frac{1}{n} - \frac{1}{n+1}\)

则：\(S(x) = \sum \frac{x^n}{n} - \sum \frac{x^n}{n+1}\)

\[\boxed{S(x) = 1 + \frac{1-x}{x}\ln(1-x), \quad |x| < 1, x \neq 0}\]

五、注意事项

  • 注意收敛域的端点需要单独检验
  • 逐项求导/积分后收敛半径不变
  • 幂级数在收敛域内可进行四则运算
  • 泰勒展开是幂级数的重要应用
